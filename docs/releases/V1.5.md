# V1.5 · 皮肤系统（白色 / 黑色）

2026-11-04 · 代码提交见本版合并记录 · [设计与实施归档](../design-archive/V1.5/README.md)

1. 新增双皮肤系统：白色（默认，外观与 V1.4 完全一致）与黑色（墨绿暗色），在「个人中心 → 外观」切换，选择本地持久化。
2. 全部页面与组件样式 token 化：约 80 处硬编码色值替换为语义 CSS 变量（`styles/tokens.wxss` 补充 token，浅色值与原值一致，白色皮肤像素级不变）。
3. 新增 `styles/skin-dark.wxss`（`.skin-dark` 作用域覆盖全部 token）与 `utils/theme.js`（皮肤状态、导航栏/窗口底色同步）。
4. `app.js` 包装全局 `Page()`，onShow 自动注入 `skinClass` 并同步导航栏颜色；26 个页面根节点绑定 `{{skinClass}}`，页面 JS 无需单独接入。
5. `bottom-nav` 移入 7 个页面根 view 内部以继承皮肤变量；`interaction.wxss` 变量改为引用语义 token，交互动效作用域自动跟随皮肤。
6. 切换皮肤带 circle-blur 动效：新皮肤底色圆从点击处扩散（blur 软边）盖住全屏后换肤再淡出，模拟 Web View Transitions 的 circle-blur-reveal。

验证：本机已做 JS 语法检查（node --check 通过）、全部 WXSS 花括号配对检查（0 处不匹配）与残留硬编码色值复查（仅 growth 页 1 处琥珀分类色有意保留）。本机未安装微信开发者工具，官方 wcc/wcsc 编译与真机黑色皮肤目测验收未完成；需在开发者工具中编译确认后再推送。
