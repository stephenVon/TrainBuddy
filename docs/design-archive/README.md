# 版本设计归档

| --- | --- | --- |

| [V1.2](V1.2/README.md) | Refined Green 教练端精修，验收限制见版本归档 | [V1.2 更新](../releases/V1.2.md) |

| [V1.4](V1.4/README.md) | 学员动作库接入公开目录，沿用 V1.3 视觉 | [V1.4 更新](../releases/V1.4.md) |
| [V1.5](V1.5/README.md) | 左侧部位、器械筛选和双列动作卡片 | [V1.5 更新](../releases/V1.5.md) |

后续按 `V1.2/`、`V1.3/` 增加；只有文档补充时不另起功能版本。没有设计变动时，在版本目录说明沿用的设计版本。
